# M6.6.1 逐页译文公式保护验收

日期：2026-09-28。设计依据：[公式保护开源产品拆解](research/2026-09-28-formula-safe-page-translation.md)。

## 已验证

- 本地真实 `data/raw/sample.pdf` 第 5 页：`pypdf` 文本层把原图的 FFN 下标压成普通字符；新保护器定位到 3 处独立显示公式，包含 FFN，生成各自的原 PDF 裁剪坐标。按该坐标实际裁出的 FFN 图片经目视确认包含完整的 `W₁`、`W₂`、`b₁`、`b₂` 与式号 `(2)`。
- 合成 PDF 自动测试：独立 `FFN` 行被替换成占位符，含 `dmodel = 512` 的普通叙述句仍发送给模型翻译；页码和裁剪区域随结果返回。
- 可抽取的数学特殊符号（例如 `−∞`、`β`、`≥`）也用占位符保护，译文返回后按原字符恢复。
- 模型若删除、重复或改写公式/符号占位符，服务器拒绝保存译文；缓存也不产生。此前的页译文因提示版本变化不会被复用。
- 完整后端测试：`108 passed`。前端 TypeScript 检查及生产构建：通过。
- 未调用用户的真实 DeepSeek API，也未上传 PDF 或公式图像。旧的本地服务进程若仍在运行，需要重启后才会使用新的 Python 逻辑；前端已重新构建。

## 边界

本次保证的是**被检测到的独立显示公式**以原 PDF 像素显示，而非模型重写。行内变量、极复杂公式、扫描件、表格和双栏顺序尚未获得结构化数学解析；译文中的这些内容仍需以中间原 PDF 为准。后续若追求可编辑 LaTeX 或逐块精确对齐，需专门的解析/OCR 方案和评测，不能仅靠翻译提示词。
