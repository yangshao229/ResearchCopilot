# M6.5.3 验收：选区翻译复用

日期：2026-09-26

## 完成内容

- 同一论文、会话、PDF 页、原文选区、同页上下文、语言策略、模型和翻译提示版本完全一致时，从现有阅读记录返回译文；命中不调用模型，不增加重复历史。
- 缓存答案仍带当前原文页的证据、引用和原记录 ID；PDF 原文不被译文替换，检索索引不混入译文。

- 旧记录缺 `prompt_version` 时正常读取但不缓存；证据不足、无引用或空答案不缓存。

## 已知边界

当前只缓存手动触发的选区翻译；不跨会话共享，也不预翻译整篇论文。缓存版本需在翻译提示或解释规则变更时同步更新。此步未做 Safari 等浏览器端人工点击验收；前端构建和后端接口已验证。完整术语表、原文语言自动检测、英文 UI 与整篇双语视图留待后续各自拆解和验收。
