# M8.U2：首次使用与本地服务恢复

日期：2026-10-05。依据：[开源产品拆解](research/2026-10-05-first-run-and-service-recovery.md)与[成品化路线](PRODUCT_COMPLETION_PLAN.md)。

## 交付

- 真正空论文库时，中央欢迎区给出“导入 PDF → 阅读原文 → 核对证据 → 写下理解并确认入库”的四步闭环，并提供不依赖左栏展开状态的 PDF 导入入口。
- 论文列表请求失败时，不再把空数组误显示成空资料库；中央区域明确说明本地服务不可用，并提供只重新读取状态的“重新检查”按钮。
- `/api/health` 返回应用版本和整数 `api_schema`。新版前端连接旧后端、健康端点缺失或契约不一致时显示兼容提醒，但仍保留能够读取的基础论文列表。
- 重试不会停止、重启或替换任何进程，也不会清空浏览器中已保存的论文、页码、研究集合或会话选择。

## 验证

- 新增健康端点契约测试；完整后端测试 `177 passed`，仅有既有的两个依赖弃用警告。
- 前端 TypeScript 与生产构建通过；仍有既有的大分块提示。
- 已自动检查健康契约、空状态分支、服务错误分支、版本警告和中央导入入口的构建完整性。受限环境已知无法监听 8010–8011，因此本轮未再次尝试浏览器服务，也未触碰任何已有进程。
- 没有修改论文、阅读记录、Vault 或翻译缓存，没有调用 DeepSeek。
