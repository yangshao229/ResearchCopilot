# M6.5.4 验收：论文级人工术语表

日期：2026-09-26。设计依据：[术语表开源产品拆解](research/2026-09-26-paper-glossary.md)。

## 本阶段结果

- 每篇论文的术语独立存于本地 `artifacts/glossary/`，用户可在阅读侧栏按翻译目标语言新增、查看、删除术语；没有自动生成或自动确认。
- 选区上下文预览会列出本次实际命中的术语，最多 8 条；未命中的词和其它论文的词不会进入翻译提示。术语是用户的译名偏好，不会作为论文证据或引用。
- 翻译记录保存命中术语的内容摘要；相关译名新增或删除后旧译文不再命中缓存，无关术语的变化不阻止安全复用。旧提示版本的翻译记录保守失效。
- 前端术语表位于可滚动的侧栏内容区，提问表单保持固定；页眉阶段徽标改为不随里程碑过期的名称。
