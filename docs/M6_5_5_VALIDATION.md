# M6.5.5 验收：原文语言判断与人工覆写

日期：2026-09-27。设计依据：[原文与界面语言开源产品拆解](research/2026-09-27-source-and-interface-language.md)。

## 已完成

- 本地抽取 PDF 前 5 页的有限文本，保守判断 `en`、`zh-CN`、`mixed`、`unknown`；扫描、公式或文本不足时不强行给出语言。
- 论文列表 API 返回自动判断；阅读侧栏显示判断，并可按当前论文手动指定英文/中文或恢复自动。
- 手动覆写复用既有论文语言偏好文件；旧 JSON 默认 `auto`。原文语言不是界面语言、回答语言或译文目标。
- 手动覆写不会改变 PDF 原文、检索证据、术语匹配或翻译目标，也不使原本可复用的译文缓存失效。

## 验证

| 检查 | 结果 |
| --- | --- |
| `.venv/bin/pytest -q` | `97 passed`；2 条既有第三方库弃用警告 |
| `npm run build`（在 `web/`） | TypeScript 与生产构建通过；保留既有大包体积提示 |
| 真实 `data/raw/sample.pdf` | 15 页，检测结果 `en` |
| 浏览器页面 | 提问侧栏显示“本地估计：英文”；原文语言、回答语言、翻译目标为独立控件，布局未遮挡提问区 |
| 无文本测试 PDF | 返回 `unknown`，不误判为英文或中文 |

纯函数测试还覆盖中文、中英混排与只取前 5 页；接口测试覆盖按论文保存、非法值拒绝和旧 JSON 兼容；翻译测试确认仅修改原文语言覆写时仍命中旧译文缓存。未调用真实 DeepSeek 或下载模型。
