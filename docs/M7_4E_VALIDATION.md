# M7.4e 行内数学真值与误报评测：阶段验收

日期：2026-10-03。

## 实现结果

- 编码前完成[开源产品拆解](research/2026-10-03-inline-math-evaluation.md)，核对 Marker、Nougat、pdfplumber 与 PDF.js 的官方资料、评测方法、失败边界和许可证。
- 新增机器可读的[人工定义合成真值账本](evaluations/m7_4e_inline_math_truth.json)，共 14 个案例，明确区分 `protect`、`leave` 和 `safe_fallback`。案例覆盖不同希腊参数、数值精度、普通希腊语、普通等号、ASCII 变量、函数、重复源文字、重复视觉位置、字形不一致、跨行、旋转和越界坐标。
- 使用同一测试驱动器重放所有合成轮廓，并锁定 14 个案例 ID 与预期决策，防止删除难例或改换类别后虚增指标。真实 `sample.pdf` 第 7 页另作本机端到端锚点，不把合成轮廓冒充跨论文真实准确率。
- 评测没有发现足以支持扩大生产正则的证据，因此保留 M7.4d 的窄边界；未修改翻译缓存、接口或用户数据。

## 指标与验证

| 指标 | 结果 | 含义 |
| --- | --- | --- |
| 受支持样本召回率 | `1.00`（4/4） | 当前声称支持的唯一希腊参数赋值均生成一个行内原图区域。 |
| 明确负样本误报率 | `0.00`（0/2） | 希腊语散文和普通等号句子均未生成公式区域。 |
| 歧义/未支持数学安全回退率 | `1.00`（8/8） | ASCII/函数表达式、重复、错字形、跨行、旋转及越界案例均保持原文。 |

- 聚焦测试：`6 passed`。
- 完整 Python 测试：`133 passed`；仅有两条既有第三方弃用提示。
- 前端 TypeScript 检查与生产构建通过；仅保留既有的大包体积提示。
- 本机真实 `data/raw/sample.pdf` 第 7 页仍按顺序得到三个行内区域；区域均在页面边界内，周围 “Adam optimizer” 与后续学习率正文保留，三处失真文字被占位符替换。该 PDF 按项目约定不随 Git 同步；另一台电脑没有此文件时只跳过这项真实样本核对，合成案例照常运行。
- 测试在调用前后比较真实 PDF 的 SHA-256，确认源文件未被修改。
- 没有读取密钥、调用 DeepSeek、生成费用、修改阅读记录或写入翻译缓存。

## 局限与下一步

- 账本中的排版变化是人工构造的机器生成 PDF 字符轮廓，不是多篇真实论文，因此不能将 `1.00` 指标解释为跨论文准确率。
- 真正扩大到一般行内公式前，仍需取得允许使用的多篇真实论文样本，为表达式及非表达式区域逐项建立人工真值。没有这些证据时继续保持安全回退。
- M7.4d 的真实 DeepSeek 逐页翻译及浏览器视觉验收已另行完成，见 [M7.4d 验收](M7_4D_VALIDATION.md)；本阶段没有重复调用 API。扫描页 OCR、VLM/LaTeX 重建、表内公式和逐块双语对齐仍不属于本阶段。
