# M8.3 显式多论文研究集合与证据聚合：阶段验收

日期：2026-10-03。

## 实现结果

- 编码前完成[开源产品拆解](research/2026-10-03-explicit-multi-paper-evidence.md)，核对 Zotero、PaperQA2 与 LlamaIndex 的官方文档、论文、源代码、许可证和失败边界。
- 新增严格只读的 `POST /api/research/evidence`：要求 2–8 个不重复论文 ID，未知 ID、重复 ID、少于 2 篇或超过 8 篇均在检索前拒绝，不能回退到全库。
- 多论文证据按用户选择顺序逐篇返回；每篇有 `matched`、`no_match` 或 `unsearchable` 状态，命中保留论文 ID、论文名、一基真实 PDF 页码、纯文本片段和本地词频分数。
- 每篇论文使用独立命中上限，不做全局 Top-K 竞争，避免一篇高频论文挤掉其他来源；损坏或无文字论文仍保留在结果中，不静默消失。
- 左侧资料库增加浏览器本地研究集合，允许明确选择、移除或清空 2–8 篇论文；选择变化会清除旧证据。界面反复说明结果只是逐篇原文证据，不是比较答案。
- 点击证据只切换到对应论文和真实页码；单篇助手的问答范围、会话与历史均不改变。

## 固定聚合逻辑评测

新增机器可读的[合成多论文真值账本](evaluations/m8_3_multi_paper_evidence_truth.json)。账本固定四篇合成文档轮廓和三个问题，覆盖两来源共同命中、范围外论文即使有命中也不得泄漏、无命中与损坏论文状态分离。

| 指标 | 结果 | 含义 |
| --- | --- | --- |
| 预期来源覆盖率 | `1.00`（3/3） | 所有声明应命中的论文都保留在分组结果中。 |
| 预期页码召回率 | `1.00`（3/3） | 三个预期论文/页码位置均被返回。 |
| 状态准确率 | `1.00`（7/7） | `matched`、`no_match`、`unsearchable` 均与账本一致。 |
| 范围泄漏率 | `0.00`（0 个越界命中） | 明确未选择但包含查询词的论文没有进入结果。 |

这些指标只验证合成页面上的范围、分组、页码和状态逻辑，不代表真实跨论文语义检索、比较或回答准确率。

## 自动验证

- 新增 3 个回归测试，覆盖固定账本指标、顺序保持、严格范围校验、单篇命中上限和来源公平性。
- 完整 Python 测试：`143 passed`；只有两条既有第三方弃用提示。
- 前端 TypeScript 检查与生产构建通过；只保留既有的大包体积提示。
- `git diff --check` 通过。
- 所有 API 测试使用临时 PDF、临时分页 JSON 和临时 processed 目录；没有写入用户论文、阅读历史、译文缓存、术语表、论文卡片或集合标签。
- 本地 `data/raw` 只有一篇真实 `sample.pdf`，不足以进行真实多论文覆盖评测；本阶段没有下载或伪造第二篇“真实论文”，也没有把合成指标冒充真实跨论文结果。
- 没有读取密钥、加载 embedding、调用 DeepSeek 或生成费用。

## 已知边界与下一步

- 当前仍是全部词同时出现的确定性原文匹配；没有查询分解、语义检索、跨论文重排序或来源质量判断。
- 研究集合只存在于当前浏览器 localStorage；不会同步或写入 M8.1 持久集合。
- M8.4 比较答案与主题笔记继续关闭。解锁前需要至少两篇允许使用的真实论文和人工固定问题集，评测来源覆盖、页码正确性、无关证据和证据不足行为；当前环境没有足够真实样本。
