# 日常阅读失败关闭回归修复

日期：2026-10-06。范围是既有语义检索、带引用回答和论文阅读路线的缺陷修复，不新增用户能力，因此按[开源产品拆解协议](OPEN_SOURCE_RESEARCH_PROTOCOL.md)复用原功能设计，不另立新功能拆解。

## 修复

- 语义和混合检索只加载已经存在于本机缓存的 `intfloat/multilingual-e5-small`。模型缺失时立即返回可理解的 503，并提示改用关键词检索；普通提问不会在后台触发 Hugging Face 下载或长时间重试。
- 同一进程内对未变化的问题和论文块限量复用向量；查询缓存最多 128 条、论文块集合最多 4 组。正文变化会形成新键并重新计算，不把旧向量当成新论文内容。
- 带引用回答显式使用 `reasoning.effort=none`，把有限输出预算留给结构化答案。Responses API 返回 `incomplete` 或 `failed` 时明确失败，不把截断或空结果保存为阅读记录。
- 中文目标的长篇页级翻译若仍主要由英文单词组成且几乎没有中文字符，会明确失败并拒绝写入译文缓存；短文本与术语、公式标记不使用该启发式误判。
- 论文专属阅读路线每种角色只采用第一个匹配的主章节，避免附录中的 Method、Experiments 等标题重复生成同类任务；没有对应主章节时仍沿用原来的保守缺省行为。

这些修改分别延续 [M4 检索评测](M4_EVALUATION.md)、[M5 阅读记录闭环](M5_VALIDATION.md)、[M6.3 论文专属阅读路线](M6_3_VALIDATION.md)与[M7.4a 截断输出修复](M7_4A_VALIDATION.md)已定义的失败关闭边界。

## 验证

- 回归测试证明缺少 Embedding 时搜索和回答均返回 503，构造模型时固定 `local_files_only=True`，关键词检索不受影响。
- 回归测试证明相同论文块只计算一次，正文变化会重算，超过容量会淘汰旧集合。
- 回归测试证明回答请求携带 `reasoning.effort=none`，并拒绝保存 `status=incomplete` 的截断结果。
- 回归测试证明中文目标的长英文原样返回不会被当成有效中文译文保存。
- 回归测试用主文章节和附录同名章节验证阅读路线保持四项，且不跳到附录重复任务。
- 完整后端测试 `181 passed`，仅有既有的两个测试依赖弃用警告；前端 TypeScript 与生产构建通过，仍有既有的大分块提示。
- 未联网下载模型、未调用 DeepSeek、未修改论文、阅读记录、Vault 或翻译缓存。
