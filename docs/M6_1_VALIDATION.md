# M6.1 第一版阅读体验补全验收

## 目标

让已经完成的 PDF 阅读、检索、DeepSeek 问答和论文卡片能力形成一个普通用户可以独立操作的阅读闭环，减少手动整理目录、终端启动和界面空间不足带来的阻力。

## 已完成

1. 网页左侧可直接导入 PDF；后端校验扩展名、文件大小和 PDF 有效性。
2. 使用 SHA-256 内容摘要识别重复论文；同名不同内容使用安全的新文件名，不覆盖原文件。
3. PDF 默认连续阅读并适合阅读区宽度；页码会随滚动更新，仍支持单页和手动缩放。
4. 资料库和 AI 助手都可收起；窄窗口改为覆盖式面板，避免三栏挤压论文。
5. 选中 PDF 原文后可选择翻译、解释、公式拆解或提问，并自动保留原文页码。
6. 页面明确提示：DeepSeek 只接收用户问题和最多 5 段本地检索证据，不接收整篇 PDF。
7. AI 回答保持草稿状态；只有填写个人理解并选择卡片栏目后，才能加入论文卡片。
8. `Start ResearchCopilot.command` 提供 macOS 双击启动入口；命令行启动也会自动打开默认浏览器。
9. 新增“信息”页，集中显示页数、本地位置、AI 数据范围和已确认笔记数量。

## 自动检查

- Python 测试：`45 passed`。
- 前端生产构建：通过。
- Python 与前端改动的格式检查：通过。

## 人工页面检查

- 本地工作台能在窄窗口中打开，资料库和助手可以独立收起或展开。
- 连续模式能同时显示相邻 PDF 页面，阅读区可以独立上下滚动。
- Safari 的 PDF 文本层兼容处理仍然生效，没有再次出现 `undefined is not a function` 启动错误。
- 右侧问题框、证据、笔记、总结和信息入口都可见，页面不会因三栏高度而截断。

## 边界

本阶段完成的是单篇论文第一版的日常阅读体验。复杂双栏、公式、表格、扫描 PDF 的解析质量检测仍属于 M7；多论文比较与资源库属于 M8。
