# M8.4d 细粒度证据充分性与独立留出集验收

日期：2026-10-04。设计依据见[开源产品拆解](research/2026-10-04-fine-grained-evidence-sufficiency.md)。本阶段只做离线评测，不修改生产检索、网页多论文 API 或生成链。

## 固定条件

- 新账本完整保留 M8.4c 的两篇 PDF、哈希、八个问题、人工页锚点和每篇三页上限，并明确标为 `calibration`。
- 新增四个未参与门槛选择的 `held_out` 自然问题：中英文训练硬件/时长正例，以及中英文 ImageNet 图像分类准确率负例。
- 正例人工锚点为 Transformer PDF 第 7 页与 BERT PDF 第 13 页。ImageNet 问题在两篇正文均无答案；BERT 第 10 页参考文献里的 ImageNet 字样被标为已知无关页，不能算答案证据。
- 继续固定本地 `intfloat/multilingual-e5-small` 修订 `614241f622f53c4eeff9890bdc4f31cfecc418b3`。新信号在 E5 隐藏状态上做查询词元到候选原文词元的最大余弦覆盖平均，不使用 pooled sentence cosine，也不声称它是经训练的 Cross Encoder。

## 校准集结果

细粒度分数仍不可分。自然/术语正例的最低分为 `0.7371592522`，负例最高分为 `0.7945405841`；负例上界显著高于正例下界。按“保住全部正例”的冻结门槛 `0.7371592522`：

- 人工页锚点：`9/9`；
- 正确拒答：`2/7`；
- 已知无关页：`0`；
- 范围泄漏：`0`。

最高负例来自 `masked language model × Transformer`，说明词元级相似度仍会把“相关术语风格”当成答案覆盖。中英文量子纠缠负例也有 5 个论文组合越过门槛。由于校准集已不可分，本信号不具备上线资格。

## Held-out 结果

冻结校准门槛后，不查看结果反调参数：

- 人工页锚点：`3/4`；英文硬件问题在 BERT 上的前三页未召回第 13 页，属于关卡之前的召回失败；
- 正确拒答：`0/4`；中英文 ImageNet 问题在两篇论文上全部被接收；
- 已知无关页：`2/24`，均为 BERT 第 10 页参考文献；
- 范围泄漏：`0`。

这同时暴露两个独立问题：现有候选召回在未见自然问题上仍会漏页；未经专门训练的 E5 词元 late interaction 无法判断“出现相关词”是否真的提供了问题所需证据。

## 自动验证与安全边界

- 新增词元覆盖、special/padding 排除、calibration-only 门槛选择与 split 回归测试。
- 完整 Python 测试 `159 passed`，仅保留既有两个依赖弃用警告。
- 前端 TypeScript 检查和生产构建通过，仅保留既有大分块提示。
- 真实评测命令：`.venv/bin/python scripts/evaluate_fine_grained_evidence.py`。评测前后均按账本复核 PDF SHA-256，分页只写临时目录。
- 未读取密钥、未联网下载模型、未调用 DeepSeek，未修改论文、阅读记录、译文缓存、卡片、标签或会话。

## 决策

M8.4d 的实验性细粒度信号失败，比较答案和主题笔记继续关闭，候选不接入生产。下一步若继续 M8.4e，需要先由用户允许取得并固定一个具备明确许可证、模型修订和离线安装方式的多语 Cross Encoder/reranker，然后使用同一 calibration/held-out 隔离重新评测；不得用 held-out 调门槛，也不得把新模型下载伪装成无权限的自动步骤。
