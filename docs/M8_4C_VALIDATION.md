# M8.4c 多论文证据门槛与页级融合验收

日期：2026-10-04。设计依据见[开源产品拆解](research/2026-10-04-multi-paper-evidence-gate.md)。本阶段只做离线评测，不修改网页多论文证据 API 或默认检索方式。

## 固定条件与真值扩展

- 完整保留 M8.4a 的两篇真实论文、SHA-256、6 个问题、人工页锚点、已知无关页和每篇 3 页上限。
- 新增[证据门槛扩展账本](evaluations/m8_4c_evidence_gate_truth.json)，只追加英文和中文两个自然形式的无证据问题。负组合从 3 个增加到 7 个，避免只用短关键词 `quantum entanglement` 验证拒答。
- 继续固定 `intfloat/multilingual-e5-small` 修订 `614241f622f53c4eeff9890bdc4f31cfecc418b3`，只从本地缓存加载；原始 PDF 与模型均不随 Git 分发。
- 页级候选在现有语义与混合排名上做确定性 RRF；没有关键词候选时保留现有混合顺序。短术语以规范化连续短语判断，其他自然问句只扫描固定模型的最大余弦相似度。

## 页级融合结果

不加拒答门槛时，页级融合将人工页锚点覆盖从 M8.4b 的 `8/9` 提升到 `9/9`。英文位置问题的 Transformer 结果变为 PDF 第 5、6、9 页，第 6 页人工锚点进入前三；BERT 第 4 页也保留。

但无门槛时 7 个预期无证据组合全部返回页面，拒答准确率为 `0/7`。因此排序改进不能单独解锁生成。

## 单一余弦门槛结果

自然正例中最低的最大余弦相似度为 `0.8169864591`，来自中文位置问题 × Transformer；自然负例中最高值为 `0.8172089757`，来自中文量子纠缠问题 × BERT。负例高于正例，两个区间发生重叠，不存在一个 `>= threshold` 的单一余弦门槛同时完整保留正例并拒绝全部自然负例。

| 门槛选择 | 人工页锚点 | 正确无证据 | 返回页 | 结论 |
| --- | ---: | ---: | ---: | --- |
| 无门槛 | 9/9 | 0/7 | 48 | 页码召回完整，但所有负例均误报。 |
| 保住全部自然正例：`0.8169864591` | 9/9 | 6/7 | 30 | 中文负例 × BERT 仍被错误接收。 |
| 拒绝全部自然负例：高于 `0.8172089757` | 8/9 | 7/7 | 24 | 丢失中文位置问题 × Transformer。 |

短术语连续短语门槛正确拒绝 Transformer 上不存在的 MLM 任务和两篇论文上的 `quantum entanglement`，同时保留 `self-attention` 与 `learning rate`。这只说明词面术语边界可解释，不解决自然问题的证据充分性。

固定账本上已知无关页计数为 0、范围泄漏为 0；已知无关页仍只是人工标注下界，不能据此宣称所有返回页均相关。两篇论文和 8 个问题也不能代表一般跨论文准确率。

## 自动验证与安全边界

- 新增页级 RRF、查询类型和门槛分支回归测试；完整 Python 测试 `151 passed`，只有两条既有第三方弃用提示。
- 前端 TypeScript 检查与生产构建通过，只保留既有大包体积提示。
- 真实评测命令：`.venv/bin/python scripts/evaluate_real_evidence_gate.py`。脚本输出完整门槛扫描、逐题逐论文分数与页码，缺少 PDF、哈希漂移或缺失模型修订时明确失败。
- 所有分页缓存均位于临时目录；运行前后 PDF 哈希一致。没有读取密钥、联网下载模型、调用 DeepSeek，或修改论文、阅读记录、译文缓存、卡片、标签和会话。

## 决策

页级融合已修复剩余英文页锚点漏检，但单一 E5 余弦门槛无法同时满足召回与安全拒答。M8.4 比较答案和主题笔记继续关闭，且本阶段候选不接入生产。下一步 M8.4d 应在保留扩展账本的前提下评测独立的“查询—原文页是否提供证据”判别信号，并增加未参与门槛选择的真实自然问题；只有页锚点和拒答在独立样本上同时通过，才讨论生成层。
