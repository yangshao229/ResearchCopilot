# M8.1 本地论文集合与标签：阶段验收

日期：2026-10-03。

## 实现结果

- 编码前完成[开源产品拆解](research/2026-10-03-library-collections-tags.md)，核对 Zotero、Paperless-ngx 与 JabRef 的官方文档、资源模型、许可证和失败语义。
- 新增独立的本地 `LibraryOrganizationStore`。集合、论文归属与标签保存在 `artifacts/library_organization/organization.json`，不移动、复制或改名 PDF，也不改变基于相对路径的论文 ID。
- 同一篇论文可加入多个扁平集合并保存多个人工标签；集合名和标签做空白规范化与大小写不敏感去重。未知集合、重复集合名、空名称、过长和过多标签会失败关闭，旧组织记录不被覆盖。
- 左侧资料库增加集合筛选、多标签交集筛选与当前论文整理面板。筛选只改变列表，当前正在阅读的 PDF、页码、会话和问答范围保持不变。
- 删除集合只解除所有论文的对应归属；论文文件、标签、阅读记录、术语表与翻译缓存均不删除。
- 所有新增可见文案和无障碍标签同时进入简体中文与英文消息表。

## 自动验证

- 新增 4 个回归测试，覆盖多对多归属持久化、标签去重、无效更新原子性、删除只解除归属、两篇论文隔离和 HTTP API 错误边界。
- 完整 Python 测试：`137 passed`；只有两条既有第三方弃用提示。
- 前端 TypeScript 检查与生产构建通过；只保留既有的大包体积提示。
- `git diff --check` 通过。
- 使用临时生成的两篇空白 PDF 和临时组织目录验证 API；没有写入真实 `data/raw`、阅读历史、论文卡片、术语表或翻译缓存。
- 尝试在空闲临时端口 `8010` 启动本地页面验收时，当前受限执行环境拒绝监听本机端口；进程随即正常退出，没有停止、替换或接触任何已有服务。静态生产构建与 FastAPI `TestClient` 端到端路由验证均已完成。
- 没有读取密钥、调用 DeepSeek 或访问外部模型。

## 已知边界与下一步

- 当前只有扁平人工集合和人工标签，不包含层级、拖放、批量编辑、自动分类或跨设备同步。
- 标签筛选采用“同时包含所有已选标签”的交集语义；全文内容搜索尚未实现。
- 组织记录引用稳定论文 ID；如果用户在文件系统中重命名论文，现有扫描逻辑会产生新的论文 ID，旧组织记录保留但不会显示。本阶段不自动迁移或清理，避免误关联。
- M8.2 应先拆解本地资料库全文搜索，明确它与单篇证据检索、当前论文问答及未来显式跨论文范围的边界；在此之前不把集合筛选扩展为跨论文问答。
