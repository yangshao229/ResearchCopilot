# M8.4f 页级多样性：离线影子诊断

日期：2026-10-06。依据[三项目／论文拆解](research/2026-10-06-page-diversity-shadow.md)。仅在既有 M8.4e 冻结的 3 篇真实 PDF、11 题、相同模型修订和相同 30 个候选上比较“Cross Encoder 重排前五片段”与“按同一排序取前五个不同 PDF 页”。未更改生产检索、证据包、问答或界面。

## 结果

| 指标 | 原有重排前 5 片段 | 页去重影子前 5 页 |
| --- | ---: | ---: |
| 8 道有答案题正确页覆盖 | 5/8 | 6/8 |
| 3 道中文有答案题 | 1/3 | 1/3 |

新增命中的唯一一题是 Transformer 训练硬件：原前五片段页码为 `8, 8, 10, 8, 2`，去重后为 `8, 10, 2, 7, 1`，正确 PDF 第 7 页因而进入前五。LoRA 中文矩阵题与 Transformer 中文位置编码题仍未命中；三个无答案问题依旧获得候选，不能因页去重而回答。报告只量化**页级锚点覆盖**，没有证明选出的单个片段包含完整答案；同页多段拼接可能反而更有用。

## 决策

**不接入默认检索或生成。** 页重复占位确实解释一个英文失败例，但不是两道中文失败题的共通原因，也没有解决证据充分性。继续保留可复跑的离线诊断字段，下一步围绕两类分开的失败做真值：一类是中文查询跨语排序，一类是“有相似片段却无答案”。不在现有 11 题上反复调门槛或添加手工查询译名。
