# M8.U1：Vault 备份与恢复指引

日期：2026-10-05。依据：[开源产品拆解](research/2026-10-05-vault-backup-recovery-guidance.md)、[数据备份与恢复说明](VAULT_BACKUP_RECOVERY.md)与[成品化路线](PRODUCT_COMPLETION_PLAN.md)。

## 交付

- Obsidian 知识库面板新增双语“备份与恢复”折叠区，明确同步不等于备份，也明确页面不会自动复制或上传文件。
- 页面列出最小保护范围：整个 Vault、尚未入库的阅读记录、稳定论文身份映射，以及没有其他可靠副本的原始 PDF。
- 提供 Obsidian 官方备份说明、macOS Time Machine 和 Windows File History 官方入口。
- 新增独立恢复清单，区分人工知识权威、运行中草稿、原始资料、可重建缓存与密钥；建议先恢复到新位置并核对，再显式重连，避免直接覆盖当前 Vault。

## 验证

- 完整后端测试 `176 passed`；仅有既有的两个测试依赖弃用警告。
- 前端 TypeScript 与生产构建通过；仍有既有的大分块提示。
- 本轮没有新增 API、依赖或文件操作。没有读取系统备份状态，没有修改 Vault、论文、阅读记录或翻译缓存，也没有调用模型。
- 尝试在 8010、8011 启动临时验收服务时，受限运行环境把监听报告为端口占用；未停止或替换任何已有进程。页面变更以生产构建完成自动验收。

## 后续

下一项成品可用性收尾应检查首次启动、空论文库与后端版本不匹配时的页面引导；不自动探测或配置用户的系统备份。
