# M8.4r：四篇真实论文的回答人工复核

日期：2026-10-09。依据：[预先固定的 8 题与裁决规则](M8_4R_HUMAN_ANSWER_AUDIT_PLAN.md)、[开源产品拆解](research/2026-10-09-human-answer-audit.md)。原始证据、模型结构化草稿、用户可见回答与 API 用量保存在本机 Git 忽略的 `artifacts/m8_4r_answer_audit.json`，不提交原文片段或密钥。

## 结果

四篇本机 PDF 的 SHA-256 与冻结题库匹配；使用现有混合检索、每题最多 5 段 PDF 原文、DeepSeek `deepseek-flash`。8 次请求全部完成，无 API 错误或截断：4 道有答案题均给出原文支持的核心答案，4 道无答案题均拒答；本样本没有观察到错误肯定或错误拒答。已回答的 4 道题均有支持核心论断的原文引用；RAG 题另外引用了与核心问题关系较弱的附录第 17 页，属于冗余解释与引用，应改进精简度。该小样本**不是盲测，也不证明一般论文上的准确率或可靠拒答**。

人工裁决分开计：有答案题 4，核心答案正确 4，错误拒答 0；无答案题 4，正确拒答 4，错误肯定 0；有答案回答中核心论断有原文支持 4，冗余引用提醒 1；API 错误 0，待复核 0。这里的“核心答案正确”不等于整篇自动摘要正确，也不等于所有扩展解释均必要；引用编号有效和语义贴切仍是两项不同检查。

## 语言偏好与调用边界

最初两道英文有答案题实际输出中文。曾为诊断提示词做一次 BERT 英文题重测，确实得到英文答案；该重测另存 `artifacts/m8_4r_language_retest.json`，用量 1,843 tokens。用户随后明确表示**无需英文题英文回答**，因此撤回强制跟随提问语言的临时改动，保持现有产品语言偏好，不把“英文问题得到中文回答”算作阅读质量错误。后续若要统一默认中文，应作为用户可选偏好的单独产品决定，而非悄悄修改。

固定 8 题合计 15,341 tokens，额外重测 1,843 tokens，共 **9 次 API 请求、17,184 tokens**。第 9 次超出原定最多 8 次的执行上限，是一次可避免的偏差；此处完整披露，不继续调用或自动重跑。费用以 DeepSeek 实际账单为准，本地 token 记录不能代替账单。评测脚本不会写阅读历史或用户 Obsidian Vault。

## 下一步边界

保持当前“读者核对原文”的提示。优先研究如何让回答只展示与问题直接相关的必要依据；不能根据这 8 道非盲测题提高准确率宣称、上线影子重排器或统一分数拒答阈值。下一次可信度评测应先冻结新论文与新问题，再运行，避免对本轮样本调参后用同一题自证有效。
