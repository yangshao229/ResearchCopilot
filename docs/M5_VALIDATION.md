# M5 本地阅读记录与人工确认验收

验收日期：2026-09-20

## 自动验证

- 问答完成后生成独立记录 ID，并保存问题、回答、模型、检索方式和真实 PDF 页码引用。
- 新建存储对象后仍能读取原记录，验证数据不是只保存在浏览器内存中。
- 未确认的 AI 记录不能导出，防止草稿静默进入正式笔记。
- 用户确认并填写个人理解后，可以生成普通 UTF-8 Markdown。
- Markdown 包含 `review_status: confirmed`、问题、回答、解释、引用页码、原文摘录、个人理解和不确定性。
- API 完成新增记录、读取历史、更新确认状态和下载 Markdown 的端到端测试。

## 真实页面验证

论文：*Attention Is All You Need*

问题：为什么 Transformer 能并行而 RNN 不行？

1. 第一次 DeepSeek 返回的结构不符合约定，页面显示错误，本地没有写入坏记录。
2. 串行重试后生成回答，并引用 PDF 第 2 页。
3. 右侧标签显示“记录 1”，记录状态为“待人工确认”。
4. 刷新整个页面后，“记录 1”仍然存在，达到持久化完成标准。
5. 没有代替用户点击“核对完成并确认”；确认状态必须表达用户亲自核对后的判断。

## 本地文件边界

- 阅读历史默认保存在 `artifacts/reading_history/`。
- 确认后的 Markdown 默认保存在 `artifacts/reading_history/exports/`，同时由浏览器下载。
- `artifacts/` 已被 Git 忽略，因此私人阅读记录不会随源代码提交。
- Markdown 是核心长期格式，不要求安装 Obsidian；以后安装后可直接打开导出目录。
