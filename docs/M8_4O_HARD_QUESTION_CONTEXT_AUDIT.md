# M8.4o：旧困难题的证据标注与同页窗口复核

日期：2026-10-08。状态：**离线影子诊断，未改生产问答**。

沿用[候选重排与拒答分离的开源拆解](research/2026-10-08-reranked-support-and-abstention-shadow.md)、M8.4g 已固定的三组中英同义困难题和三条中文无答案题。本轮先按问题实际语义重审[人工原文短语账本](evaluations/m8_4m_hard_set_support_spans.json)：LoRA 题只要求指出可训练的 A/B；BERT 题只要求指出随机选择 15% 的词元位置；Transformer 题仍要求位置编码及正弦／余弦。冻结 W0 和 80/10/10 替换方案是真实论文内容，但不是这两道题的必要回答条件，不能拿它们制造假阴性。账本版本升级并继续校验 PDF SHA-256、数据集 ID 和同页共现。

## 固定的前 30 候选与前 5 展示预算

| 数据集 | 原始片段 Top-5 | mMARCO 原片段 Top-5 | mMARCO + 后一个同页片段 | mMARCO + 后两个同页片段 |
| --- | ---: | ---: | ---: | ---: |
| 旧困难题，6 条中英问法 | 0/6 | 0/6 | 1/6 | 3/6 |
| 既有三论文较易题，12 条中英问法 | 5/12 | 11/12 | 11/12 | 11/12 |
| 独立 RAG 论文，8 条中英问法 | 7/8 | 7/8 | 8/8 | 8/8 |

旧困难题的 6/6 正确 PDF 页均已进入前 30 候选，但仅 3/6 有精确的必要短语进入前 30 **原始片段**。这解释了“找对页却找错片段”的一部分现象。英文 LoRA 的答案位于已排序到前五的同页片段之前第二格；英文 Transformer 和中英 BERT 可在命中片段之后一至两格找到关键句。中文 LoRA、中文 Transformer 仍未由这些窗口补回。这里每组中英问法是同一个知识点的两种提问，不是六个独立概念。

代价明显：在旧困难题上，mMARCO 原片段前五平均约 `4,657` 字符；向后补两个同页片段约 `10,115` 字符，约 **2.17 倍**。向前补两个只有 `1/6`，平均约 `9,557` 字符。对既有三论文较易题，后两个片段比原重排多约 2.23 倍字符却没有新增成功题；独立 RAG 论文也没有超过只补一个片段的 `8/8`。这不是一个值得默认施加于所有问题的固定窗口。

三条中文无答案题的 mMARCO 最高分仍与有答案题重叠：正例最高候选分数最低 `-0.3431`，负例最高候选分数最高 `1.6792`。窗口实验没有生成答案，也不能证明系统会正确拒答。`support_spans_present` 只表示原文短语在同一页被取回，并不判断内容关系、翻译质量或引用忠实。

## 决策与下一步

**不接入固定两片段窗口、不启用 mMARCO、不用分数阈值拒答。** 下一步针对已召回正确页却没召回答案片段的中文问题，比较有限候选内的页内片段补充、切分边界或跨语候选生成；要把额外文本量作为硬指标，并在独立论文和无答案题上复核。生成阶段的拒答单独验收。任何生产改动都必须使用户看到的证据与模型实际收到的证据一致。

本轮只读本机公开 PDF、E5 和固定本地 mMARCO 修订；不联网下载模型、不调用 DeepSeek、不改 PDF、译文缓存、阅读记录或真实 Vault。Mac 已实测，Windows 未实测。脚本新增可选 `--extended-windows`，默认三种旧视图不变，并在每题输出命中的 PDF 页码与片段序号，便于核查“页对、片段错”。

全量 Python 测试 `211 passed`，前端 TypeScript 与构建通过；现有第三方依赖给出 2 条弃用警告，前端仍有既有的大分块提示。默认脚本调用只返回旧的三种视图，通过兼容性复跑；`git diff --check` 与账本 JSON 格式检查通过。
