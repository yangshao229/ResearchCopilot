# M6.6 验收：按需翻译当前 PDF 页

日期：2026-09-28。开源对照与决策见 [调研](research/2026-09-28-page-translation.md)。

## 交付范围

- 阅读器右侧新增“译文 / Translation”标签；显示当前 PDF 原文页码、目标语言、明确的 API 发送范围与可能产生的用量。
- 进入标签或翻页只检查本地缓存；“翻译当前页”点击后才将本页可抽取文本交给 DeepSeek。原始 PDF 不被替换。
- 本地缓存按论文、页码、原文、目标语言、术语策略、该页命中的人工术语、模型和提示版本隔离；“重新翻译”明确再次调用 API。
- 没有可抽取文本或文本超过 10,000 字符时不发送模型请求；翻译失败或空译文不写缓存。
- 译文是页级参考文本，不是逐段或公式/图表精确重排；待 M7 布局解析后再提高对照精度。

## 当前限制

页面正文可读性取决于 PDF 文本层。扫描件需要 OCR，双栏、公式、表格和脚注可能发生抽取顺序偏差；任何译文都应核对中间原文。整篇自动翻译和精确双语对齐尚未完成，不能将本阶段称为全文翻译完成。
