# M6 成熟论文卡片验收

验收日期：2026-09-21

## 设计选择

论文卡片不再调用模型进行第二次自由总结，而采用“用户确认 + 用户分类 + 固定模板编译”：

1. AI 回答首先保存为待确认阅读记录。
2. 用户核对 PDF 引用，写下自己的理解。
3. 用户把记录归入一句话结论、研究问题、方法、实验、贡献、局限或未解决问题。
4. 系统只读取已确认记录，按固定模板生成 Markdown 预览。

这样能避免模型在总结阶段添加没有原文依据的新结论，并使卡片中的每段内容都能追溯到阅读记录和 PDF 页码。

## 自动验证

- 少于两条已确认记录时拒绝生成卡片。
- 未确认记录不会进入卡片。
- 已确认记录按照人工选择的栏目排列。
- 用户个人理解优先展示，AI 辅助回答折叠保留。
- 每条记录保留原文页码、摘录和阅读记录 ID。
- 缺少内容的栏目明确显示 `TODO`，不自动编造。
- 第一次导出生成普通 UTF-8 Markdown。
- 已有同名正式卡片时拒绝覆盖，并在页面提供统一差异预览。
- 用户确认差异后只能导出带时间戳的新版本，旧文件保持不变。
- API 端到端测试覆盖预览、首次导出、拒绝覆盖和版本化导出。

## 真实页面验证

- 页面标题显示 `M6 · 成熟论文卡片`。
- “记录”页为每条记录显示论文卡片栏目选择器。
- “总结”页显示当前已确认记录数，并在不足两条时禁用预览按钮。
- 当前真实论文只有一条待确认记录，因此显示 `0 条已确认记录`；没有代替用户确认或伪造第二条记录。

## 本地文件边界

- 正式论文卡片默认保存在 `artifacts/paper_cards/`。
- 该目录已被 Git 忽略，不会将私人笔记提交到源代码仓库。
- 导出格式为普通 Markdown，不依赖 Obsidian。
