# 逐页译文中的公式保护：开源产品拆解

检索日期：2026-09-28。

## 用户问题

科研 PDF 的文本层会丢失上/下标、根号或双栏关系。样例论文第 5 页的可见原文是带下标的 `W₁`、`d_model` 等，但当前 `pypdf` 抽取为 `W 1`、`dmodel`；再让语言模型誊写公式，会把不可靠的文字层伪装成可信译文。用户要在读中文解释时仍能核对公式和特殊符号。

## 参考项目与一手资料

| 项目 | 官方依据 | 成熟做法 | 许可证及取舍 |
| --- | --- | --- | --- |
| [BabelDOC](https://github.com/funstory-ai/BabelDOC/blob/main/docs/ImplementationDetails/ILTranslator/ILTranslator.md) | 官方中间层翻译设计 | 先将公式识别为独立组件，翻译时用占位符，输出后按位置复原；纯公式段落可跳过翻译。 | AGPL-3.0。借鉴隔离公式的原则，不引入代码或完整排版引擎。 |
| [PDFMathTranslate-next](https://github.com/PDFMathTranslate/PDFMathTranslate-next/blob/main/README.md) | 官方 README 与[高级配置](https://github.com/PDFMathTranslate/PDFMathTranslate-next/blob/main/docs/en/advanced/advanced.md) | 翻译 PDF 时保留公式、图表和批注，并允许按字体/字符规则排除翻译；支持按页处理和双语对照。 | AGPL-3.0。借鉴原文可回看、逐页处理，不引入其全篇 PDF 重排链。 |
| [MinerU](https://github.com/opendatalab/MinerU) | 官方仓库 | 复杂公式要靠专门的版面分析与公式识别才能转 LaTeX；单纯文字抽取不能保证数学结构。 | AGPL-3.0，模型/运行成本较高。本阶段不引入；未来如需可编辑 LaTeX，再单独评估。 |

## 流程拆解与对 ResearchCopilot 的取舍

| 维度 | 采用 | 暂不采用 |
| --- | --- | --- |
| 交互 | 右侧逐页译文中，检测到的独立公式用原 PDF 局部图像显示；原文页始终在中间可核对。 | 自动把整篇重排成双语 PDF。 |
| 数据 | 只给现有 `PageTranslation` 增加可选公式区域；区域仍锚定当前论文与 PDF 原页码。 | 新建独立的“公式数据库”或复制 PDF。 |
| 模型 | 本地将独立公式及可直接提取的数学特殊符号替换为稳定占位符，再送当页其余文本；模型必须原样返回每个占位符，否则失败，不缓存。 | 让模型猜测 LaTeX 或修复 PDF 已损坏的数学语义。 |
| 呈现 | 浏览器从用户本机的同一 PDF 裁出原始公式像素，保留上/下标、根号及特殊字体。 | 把 PDF 文本层误当成排版真实来源。 |
| 隐私 | 仅用户主动点击翻译时发送经遮蔽的本页文字和命中术语；原 PDF 和公式图像不上传。 | 上传整个 PDF 或页面截图。 |
| 失败 | 无法定位公式时保留原文页并给出明确提醒；模型破坏占位符时报错，不输出看似完整的译文。 | 静默省略公式或用猜测文本代替。 |

样例第 5 页实测：原 PDF 中的 FFN 公式有下标；`pypdf.extract_text()` 已把 `W₁` 拉平为 `W 1`，`d_model` 拉平为 `dmodel`。因此仅增加一句“请保留公式”的提示词不能修复此类错误。

## 架构影响与兼容性

- 复用现有逐页 PDF、`PageTranslationService`、翻译缓存和当前页侧栏；不修改检索索引、问答、笔记和论文卡片。
- 公式区域由当前 PDF 本地派生，缓存键提高版本以免复用旧的不安全译文。
- 不同论文、页码、目标语言、术语和会话：仍沿用已有隔离；公式图像总是从当前论文当前页读取，不共用其它论文的图像。
- macOS/Windows：Python 只用已有 `pypdf`；浏览器只用已有 PDF.js，不依赖 Poppler、系统字体或外部公式 OCR。
- 中文/英文译文：占位符不翻译；界面语言与译文目标仍独立。
- 局限：本步只保证检测到的**独立显示公式**的可见原貌。行内公式、表格、扫描页及复杂布局仍可能有抽取误差，必须对照左侧 PDF；后续需要版面/公式识别再追求可编辑的数学表达。

## 实现顺序与验收标准

1. 从真实 PDF 中定位独立显示公式所在行及裁剪区域；无法定位时不伪造图像。
2. 翻译前以占位符替换对应公式行与可提取的数学特殊符号；校验译文中每个占位符恰好出现一次；缓存隔离旧版本。
3. 侧栏在对应位置渲染 PDF 原始公式裁图，并明确原文公式优先。
4. 单元测试覆盖公式遮蔽/恢复、模型篡改标记失败、缓存与跨页隔离；真实样例第 5 页核对 FFN 下标；全量后端测试和前端构建通过。

## 暂不实现

不声称所有行内特殊符号已自动转为正确 LaTeX，也不自动翻译含公式的图表或用模型重建扫描页。此能力需要更专门的解析器与独立评测。
