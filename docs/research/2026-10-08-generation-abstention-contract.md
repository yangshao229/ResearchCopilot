# 生成阶段证据不足与拒答契约：开源方案拆解

日期与一手资料复核：2026-10-08。目标是修复“模型自称证据不足，却仍把未经证实的结论展示为答案”的安全缺口；不更改检索排名，也不调用真实 DeepSeek。

## 用户问题与现状

ResearchCopilot 已有 `EvidenceSet`、固定引用编号及 `insufficient_evidence` 字段。当前服务在没有证据、或模型不提供有效引用时会拒答；但模型若同时返回 `insufficient_evidence=true`、貌似确定的 `answer` 和有效引用编号，服务仍原样展示该回答。引用编号有效仅说明它指向当前证据，不说明证据真正支持结论。论文阅读中，这种状态不应被当成可确认的知识。

## 参考项目、流程与取舍

| 一手来源 | 成熟做法 | 本项目取舍 |
| --- | --- | --- |
| [Haystack AnswerBuilder 官方说明](https://docs.haystack.deepset.ai/docs/answerbuilder) | 把生成结果和引用文档组织成明确的答案对象；可只列实际引用的文档，而非全部候选 | 借鉴“答案—引用显式绑定”，继续使用现有 `EvidenceSet.citations_for`，不引入 Haystack |
| [LlamaIndex FaithfulnessEvaluator 官方说明](https://docs.llamaindex.ai/en/v0.9.48/module_guides/evaluating/usage_pattern.html) | 单独评估回答与检索上下文是否一致，而不是把相关性当忠实度 | 区分引用合法性与语义忠实；本轮不接入另一个 LLM 评判器，费用和误判留待独立验收 |
| [Ragas Response Groundedness 官方说明](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/nvidia_metrics/) | 逐断言检查回答是否由上下文支持，并区分部分与完全支持 | 学习其“全部陈述要有支持”的验收方向；本轮不把字符串覆盖或引用编号冒充语义判定 |
| [SQuAD 2.0 原论文](https://aclanthology.org/P18-2124/) | 把貌似相关的无答案题与有答案题一起评测 | 固定空证据、无效引用、模型自报不足与貌似相关证据的测试；不从检索分数推断可回答性 |

以上只借鉴方法，不复制代码或引入依赖，因此无新增许可证传播、模型下载或跨平台运行负担。项目现有模型 API 与 UI 不增加新状态字段。

## 阅读流程与数据边界

用户先核对最多五段带原始 PDF 页码的证据；生成模型只接收这份 `EvidenceSet`。若证据为空，不调用模型；若模型给出未知或空引用且自称能回答，拒绝展示；若模型**自报证据不足**，无论其回答文字和引用编号如何，都仅展示安全、明确的“尚不能据此下结论”，但保留原始证据供用户回看。只有模型自报足够且至少引用一个当前证据编号时，才进入现有回答展示流程。这个契约不能证明“有编号的肯定回答一定正确”；需要未来独立的人工语义真值和生成评测。

不改变 PDF、切分、检索、页码来源、翻译缓存、阅读记录格式或真实 Vault；不会自动确认笔记。若模型自报不足，服务不应把其原始断言写为可确认的回答。译文任务同样避免展示模型判定失败时的残缺译文。不同会话与中英界面共用同一安全状态，提示文字依既有论文语言策略提供简中或英文；原文及证据页码不随语言切换。

## 实现与兼容性矩阵

| 场景 | 预期 |
| --- | --- |
| 当前论文／跨论文 | 只处理传入的当前 `EvidenceSet`；不合并其他论文证据 |
| 原文问答／选区翻译 | 自报不足时都不展示残缺结论；证据仍供核对 |
| 不同会话 | 服务无新增会话状态；记录仍由已有流程管理 |
| 本地／云端 | 只用本地假模型测试；真实 DeepSeek 行为不在本轮宣称已验证 |
| macOS／Windows | 纯 Python 状态处理和测试应跨平台；本轮只在 Mac 执行 |
| 正例／负例 | 正例有效引用维持旧行为；空证据、无效引用和自报不足必须失败关闭；相关但不充分的证据另记为未解决边界 |

## 验收与明确不做

先写针对现有缺口的失败测试：模型自报不足同时返回肯定结论和有效引用，结果不得暴露那句结论，且不得把它当可确认回答。随后在现有 `PaperAnswerService` 内做最小修补，不新建回答类或存储。全量 Python 测试、前端构建及现有证据快照测试通过。只改这一处安全契约，不引入新评分器、阈值、自动生成评测、付费 API 调用或真实 Vault 写入。不得据此宣称所有无答案题都能被模型识别，因为模型若错误地声明 `insufficient_evidence=false` 且引用了相关但不支持的片段，确定性校验仍无法识别。
