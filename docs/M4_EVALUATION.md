# M4 混合检索与重排序评测

评测日期：2026-09-20

论文：*Attention Is All You Need*

## 方法

- 关键词检索：按问题词项在原文片段中的命中次数排序。
- 语义检索：使用本地 `intfloat/multilingual-e5-small` 比较中文问题与英文原文的向量相似度。
- 混合检索：分别取得关键词与语义候选，使用 Reciprocal Rank Fusion 合并名次；关键词权重为 `0.8`，语义权重为 `1.0`，常数 `k=60`。
- 轻量重排序：增加正文线索与词项重合奖励，降低参考文献列表、致谢类片段的权重；原始名次、融合分、惩罚和最终分全部保留。
- 每种方法返回前 5 个片段。相关页由人工预先标注，评测脚本不根据检索结果修改答案。

固定问题集保存在 `evaluation/retrieval_questions.json`，可重复运行：

```bash
uv run python scripts/evaluate_retrieval.py data/processed/9ca16b5750b0b7df.json
```

## 汇总结果

| 策略 | Mean Recall@5 | MRR |
| --- | ---: | ---: |
| 关键词 | 1.00 | 0.90 |
| 语义 | 1.00 | 0.90 |
| 混合检索 + 重排序 | 1.00 | **1.00** |

Recall@5 表示前 5 条结果覆盖了多少人工标注的相关页；MRR 更关注第一条相关证据出现得是否足够靠前。

## 结论与边界

1. 三种方法在这个小问题集上的 Recall@5 相同，差异主要体现在排序质量；因此只看“有没有召回”不足以判断阅读体验。
2. 混合策略让 5 个问题的首条证据都落在人工标注页，MRR 从 `0.90` 提升到 `1.00`。
3. 当前评测集只有一篇论文和 5 个问题，结果用于回归检查，不代表对所有 AI 论文都成立。
4. 当前重排序是透明规则，不是学习型 Cross-Encoder。后续扩充多论文评测集后，再判断是否值得增加更重的模型。
