# M8.2 本地资料库全文搜索：阶段验收

日期：2026-10-03。

## 实现结果

- 编码前完成[开源产品拆解](research/2026-10-03-library-full-text-search.md)，核对 Zotero、Paperless-ngx 与 JabRef 的官方搜索文档、接口、许可证和失败边界。
- 新增只读 `POST /api/library/search`。请求必须显式携带论文 ID 范围；未知 ID 返回范围错误，空范围保持为空，绝不静默扩大为全部论文。
- 复用 `PaperSearchService` 的本地分页抽取缓存，以大小写不敏感的“全部查询词同时出现”规则查找 PDF 原文。结果包含论文 ID、论文名、一基真实 PDF 页码、纯文本片段和词频分数，并以确定性顺序返回。
- 每篇论文最多返回有限页面位置，全局结果有上限。单篇 PDF 无可抽取文本或解析失败时继续搜索其他论文，并单独返回跳过数量；没有命中与无法搜索不会混为一类。
- 左侧资料库增加显式提交的原文搜索、范围说明、零结果和跳过提示。当前集合与标签筛选后的可见论文就是搜索范围；点击结果只打开目标论文和页码，不调用问答接口、不生成跨论文答案。
- 所有新控件、空状态、失败提示和无障碍文案同步进入简体中文与英文消息表。

## 自动验证

- 新增 3 个回归测试，覆盖多词同现、真实页码、片段截断、显式跨论文范围、单篇损坏隔离、未知 ID 拒绝和空范围语义。
- 完整 Python 测试：`140 passed`；只有两条既有第三方弃用提示。
- 前端 TypeScript 检查与生产构建通过；只保留既有的大包体积提示。
- `git diff --check` 通过。
- 使用临时 PDF、临时分页 JSON 和临时 processed 目录完成 API 验收；没有写入真实阅读历史、翻译缓存、术语表、论文卡片或集合元数据。
- 对本机真实 `data/raw/sample.pdf` 在临时缓存目录执行只读查询 `attention`，前五个位置为 PDF 第 4、5、2、6、1 页；搜索前后源 PDF SHA-256 一致。
- 没有读取密钥、加载 embedding、调用 DeepSeek 或创建阅读记录。

## 已知边界与下一步

- 当前是确定性词面全文查找，不提供词干化、模糊匹配、中文分词、短语/正则/字段语法或语义搜索。
- 只搜索 PDF 可抽取原文；扫描件显示为跳过且不执行 OCR。结果片段是定位线索，不是经过人工确认的论文结论。
- 搜索范围来自当前集合与标签筛选，但搜索结果不会改变助手的单篇论文问答范围。
- M8.3 应先实现显式的多论文研究集合选择和范围确认，再评测跨论文证据聚合；未通过固定问题集前不生成比较结论或主题笔记。
