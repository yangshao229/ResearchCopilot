# M8.4e 多语重排序器离线影子评测

日期：2026-10-06。状态：**只完成离线比较，未接入产品默认检索或问答**。设计依据见[开源模型候选拆解](research/2026-10-06-retrieval-reranker-candidate.md)。

## 固定材料与方法

- 真实 PDF：LoRA v2、Attention Is All You Need、BERT NAACL 2019。评测开始前逐篇校验 SHA-256；锚点均使用从 1 开始的 PDF 文件页码。已目视核对 LoRA 第 4 页低秩矩阵、Transformer 第 6 页位置编码、BERT 第 4 页遮盖语言模型；其他硬件问题沿用此前的[固定真值](evaluations/m8_4d_fine_grained_evidence_truth.json)。
- 固定 [11 道问题及页锚点](evaluations/m8_4e_reranker_truth.json)：8 道有答案（英 5／中 3），3 道无答案。先用现有关键词＋E5＋RRF 取每篇前 30 个片段，再用固定修订 `1427fd652930e4ba29e8149678df786c240d8825` 的本地 Cross Encoder 对相同候选重排；两路都比较前 5 个片段是否覆盖正确 PDF 页。
- 通过 `HF_HUB_OFFLINE=1`、`TRANSFORMERS_OFFLINE=1` 和 `local_files_only=True` 运行；只加载被 Git 忽略的 `data/model_cache/`。无 DeepSeek 调用、无论文上传、无真实 Vault 写入。评测命令：`.venv/bin/python scripts/evaluate_reranker.py`。

## 结果

| 指标 | 现有排序 | 影子重排 |
| --- | ---: | ---: |
| 8 道有答案题：正确页进入前 5 | 2/8 | 5/8 |
| 英文有答案题 | 2/5 | 4/5 |
| 中文有答案题 | 0/3 | 1/3 |
| 已标记的无关页进入前 5 | 0 | 0 |

每题“正确页首次名次”（越小越好，候选池上限 30）：

| 论文／问题 | 现有 | 影子重排 |
| --- | ---: | ---: |
| LoRA 训练哪些矩阵（英） | 8 | 1 |
| LoRA 训练哪些矩阵（中） | 9 | 8 |
| Transformer 位置编码（英） | 15 | 2 |
| Transformer 位置编码（中） | 23 | 11 |
| Transformer 训练硬件与时长（英） | 7 | 7 |
| BERT 遮盖语言模型（英） | 3 | 4 |
| BERT 遮盖语言模型（中） | 9 | 1 |
| BERT 训练硬件与时长（英） | 3 | 4 |

全部 8 个正确页都在原始前 30 个候选中，因此本次失败主要在排序而非候选召回。影子模型没有让原本前 5 已命中的题掉出前 5，但中文仍有 2/3 未命中，Transformer 硬件题也未修复。这份小样本不足以宣称跨论文稳健。

三道无答案题依然会得到最高分片段：LoRA `0.24`、Transformer `-4.17`、BERT `-0.99`。分数与部分有答案题重叠，不能用一个未经校准的分数门槛声称可靠拒答。重排只决定“先看哪段”，不决定“论文是否提供了足够证据”。

本机 CPU 对每道题的 30 个候选打分约 `0.49–0.65s`，不含首次载入、PDF 解析和 E5 召回；仅为一次测试机测量。完整 Python 测试 `186 passed`，两条第三方弃用警告；前端虽未改动，仍重新执行了 TypeScript 与生产构建并通过，只有既有的大分块提示。
